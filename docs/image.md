## 各画面詳細

### 1. プレビュー画面

| 要素 | 内容 |
|------|------|
| Canvasエリア | 絵本プレビュー（モザイクあり）・ページ送りボタン |
| タイトル | 編集可能なテキストフォーム |
| SNSシェアボタン | モーダル起動 |
| DLボタン | 決済画面へ遷移（book_type=pdf） |
| 製本ボタン | 決済画面へ遷移（book_type=print） |

### 2. SNSシェアモーダル

| 要素 | 内容 |
|------|------|
| サムネ表示 | 表紙Canvas（顔合成＋タイトル＋キャッチコピー） |
| シェアボタン | X / LINE / Instagram |

※InstagramはURL共有不可のため、画像DL→アプリ起動の誘導

### 3. 決済画面

| 要素 | 内容 |
|------|------|
| 購入内容確認 | 商品名・金額 |
| 入力フォーム | 名前・メール（共通）、郵便番号・住所（製本時のみ表示） |
| 決済ボタン | Square Checkoutへ遷移 |

### 4. PDFダウンロード画面

| 要素 | 内容 |
|------|------|
| Canvasエリア | 絵本プレビュー（モザイクなし） |
| DLボタン | PDF取得・ダウンロード |
| 誘導エリア | エホンゴトへのリンク・製本案内 |

### 5. 製本完了画面

| 要素 | 内容 |
|------|------|
| Canvasエリア | 絵本プレビュー（モザイクなし） |
| 完了メッセージ | 受付完了・メール送信済み案内 |
| 誘導エリア | エホンゴトへのリンク |
