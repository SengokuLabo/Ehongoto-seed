# 要件定義

最終更新：2026-07-10

---

## サービス概要

### えほんごとのたねとは
- エホンゴト（既存サービス）へのフロントサービス
- 質問回答 → AI文章生成 → 画像選択 → 絵本自動生成
- B2C、ブラウザ完結

### エホンゴトとの関係
- エホンゴト：想いを本格的な絵本にするサービス（製作費50万円、クラファンで補填）
- えほんごとのたね：気軽に絵本を体験できる入口、エホンゴトへの誘導が最終目的
- 品質は意図的に中程度（高品質にするとエホンゴトへ誘導できなくなるため）

---

## ビジネスモデル

### ファネル構造

```
えほんごとのたねDL（300円程度）
　↓ 体験・愛着
製本（2,500〜3,000円）
　↓ 本格的に残したい
エホンゴト（自己負担5万円〜）
```

### 収益方針
- えほんごとのたね単体の黒字化より、エホンゴトへの誘導装置として位置づけ
- インフラはエホンゴトと共有のため追加固定費はほぼなし
- 初期想定利用者数：月10〜99冊

## 機能要件

### ユーザーフロー

1. 質問フォーム回答（独自React画面）
2. AI文章生成（POST /api/generate）
3. 顔パーツ選択（CanvasでリアルタイムプレビューP）
4. 背景イラスト選択（ページごとに選択）
5. プレビュー確認（ウォーターマークあり）＋ SNSシェア（任意）
6. Stripe決済（Checkout遷移）
7. 購入後：PDFダウンロード（ブラウザ側で生成・30日間再DL可）

### 絵本生成

| 項目       | 内容                                     |
|------------|------------------------------------------|
| ページ数   | 見開き複数（表紙・本文・裏表紙）         |
| 文章       | AIが質問回答をもとに自動生成（Claude Haiku） |
| タイトル   | AI自動生成（ユーザー編集は将来対応）     |
| 画像       | 事前用意したイラストから選択（AI生成なし）|
| 顔パーツ   | 髪・目・鼻・口を選択 → Canvasでブラウザ合成 |

### プレビュー

| タイミング | 内容                                     |
|------------|------------------------------------------|
| 購入前     | ウォーターマークあり、Canvasレンダリング |
| 購入後     | ウォーターマークなし、jsPDFでDL         |

### SNSシェア
- 表紙1枚をCanvasで生成（顔合成＋タイトル）
- サーバー保存なし、ブラウザから直接SNSへ渡す

### 決済
- Stripe Checkout（Stripe管理画面でカード情報処理）
- PDFダウンロード：300円
- 製本（小冊子）：3,000円
- 製本（ハードカバー）：8,000円

### ユーザー登録
- 不要（購入時に名前・メールアドレス・電話番号のみ取得）

---

## 非機能要件

### コスト方針
- ランニングコストを最小化
- 変動費：1冊あたり約2〜4円（AI生成コスト）
- 月50冊の場合の追加変動費：約175円/月

### パフォーマンス・通信費
- プレビュー・顔合成・SNSサムネはCanvas（ブラウザ側）で処理 → サーバーコストなし
- PDF生成はjsPDF（ブラウザ側）→ サーバーストレージ不要
- 顔パーツ・イラストはEC2ローカル + Nginx配信

## 技術構成

| 項目       | 内容                                   |
|------------|----------------------------------------|
| Backend    | Django（独立プロジェクト）             |
| Frontend   | React（Vite）、独自質問フォーム含む    |
| インフラ   | エホンゴトのEC2（t3.micro）・RDSに相乗り |
| DB         | 同一RDSインスタンス内に新規DB作成      |
| ストレージ | EC2ローカル（顔パーツ・イラスト）      |
| 決済       | Stripe Checkout                        |
| AI         | Claude Haiku（コスト優先）             |
| メール     | AWS SES                                |
| PDF生成    | jsPDF（ブラウザ側）                    |
| 画像処理   | Canvas API（ブラウザ側）               |
| ドメイン   | ehongotoseed.jp（取得予定）            |
